# Registre des relectures · Review log

Chaque relecture externe (REVIEW.md, pistes A, B, C) est consignée ici **après accord de
son auteur**, telle qu'elle a été remise, avec la réponse de l'auteur d'ASTRA objection par
objection. Rien n'est réécrit : une correction ultérieure s'ajoute, elle ne remplace pas.
*Each external review is recorded here, as submitted and with its author's consent,
together with a point-by-point response. Nothing is rewritten; later corrections are added.*

## Gabarit · Template — `reviews/<piste>-<AAAA-MM-JJ>-<relecteur>.md`

```markdown
# Relecture <A|B|C> — <nom ou « anonyme »> — <date>

- Version relue : v<x.y.z> · empreinte de MANIFEST.sha256 : <sha256>
- Indépendance (REVIEW.md, critères 1–4) : <déclaration du relecteur>
- Conflits d'intérêts, outils d'IA utilisés : <déclaration>

## Rapport (verbatim)
<texte remis>

## Réponses
| # | Objection (citée) | Réponse | Modification (commit / version) ou motif du refus |
|---|---|---|---|
```
